# Node.js CI/CD Projesi

  Docker ve GitHub Actions kullanarak CI/CD öğrenmek için oluşturulmuş örnek bir Node.js API projesidir.

  ## Endpoint'ler

  - `GET /` — Uygulama bilgisi
  - `GET /health` — Sağlık kontrolü

  ## Uygulamayı çalıştırma

  Bağımlılıkları yükleyin:

  ```bash
  npm install

  Uygulamayı başlatın:

  npm start

  Testleri çalıştırın:

  npm test
